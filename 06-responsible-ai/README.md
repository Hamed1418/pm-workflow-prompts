# 06 - Responsible AI & Enterprise Data Governance

## 📌 Overview
This module outlines governance guidelines, data privacy standards, and ethical AI usage principles within project management and engineering environments.

## 🛡️ Governance Framework & Guidelines

### 1. Data Privacy & Confidentiality
- Never input personally identifiable information (PII), proprietary contract figures, or confidential stakeholder identities into public LLM interfaces.
- Utilize generic placeholders (e.g., `[Project Name]`, `[Supplier X]`, `[Duration]`) across all operational prompt templates.

### 2. Output Validation & Accountability
- AI tools function as decision-support instruments; final project sign-offs and technical decisions remain under the explicit responsibility of the certified Project Management Engineer.
- Enforce mandatory human-in-the-loop (HITL) review for all external and executive communications.
