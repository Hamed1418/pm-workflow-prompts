## 📌 Project Overview
This repository contains an executive-level **AI Workflow Pack** designed to transform unstructured project notes, scattered team updates, and complex inbox communications into actionable executive summaries, structured decision-tracking tables, and risk mitigation plans.

The project demonstrates end-to-end prompt engineering frameworks (such as **C.A.R.E.** and the **Verification Pass**) tailored for civil and software project management environments, ensuring high-density, skimmable, and hallucination-free outputs.

---

## 🛠️ Included Workflows

1. **Stakeholder Delay Notice:** Generates structured issue-escalation emails distinguishing confirmed facts from unconfirmed assumptions.
2. **Text-to-Table Converter:** Transforms raw meeting notes into a standard 5-column Markdown decision-tracking matrix.
3. **Executive Brief & Decision Tracker:** Synthesizes complex operational notes into executive-ready bullet points paired with action item tables.
4. **Overloaded Inbox Triaging:** Evaluates high-pressure launch scenarios (e.g., TaskFlow case study) to extract minimum acceptable scopes (MVP) and assign team ownership.

---

## ⚙️ Technical Documentation & Operational Usage

### Core Methodology
- **C.A.R.E. Framework:** Directs AI interactions via explicit **C**ontext, **A**ction, **R**ole, and **E**xpected Output specifications.
- **Verification Pass Protocol:** Implements rigorous step-by-step verification to trace all AI-generated claims back to the raw input, preventing factual hallucinations.
- **5-Column Standard Schema:**
  - `Workstream/Item` | `Status` | `Owner/Stakeholder` | `Key Issue / Action Needed` | `Next Milestone`

### How to Use
1. Clone this repository:
   ```bash
   git clone [https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git](https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git)

```

2. Navigate to the `/prompts` or `/workflows` directory.
3. Copy the desired Markdown prompt template and paste your raw operational notes into the `[Input Context]` placeholder.
