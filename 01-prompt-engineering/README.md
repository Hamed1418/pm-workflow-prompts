# 01 - Prompt Engineering & Starter Kit

## 📌 Overview
This module demonstrates core prompt engineering strategies (C.A.R.E. framework) tailored for civil engineering and project management tasks.

## 📝 Prompt Starter Kit Matrix

| Prompt Name | Purpose | The Prompt Itself | Example Output | Notes |
| :--- | :--- | :--- | :--- | :--- |
| **تحديث الجدول الزمني للمالك** | إبلاغ المالك بتعديل تسليم المشروع وطلب الموافقة رسمياً. | **Context:** أنا مهندس إدارة مشروع في [اسم المشروع]...<br>**Task:** اكتب إيميل رسمياً للمالك.<br>**Tone:** استراتيجي، واثق.<br>**Requirements:** اذكر التاريخ الجديد والسبب... | إيميل رسمي يوضح التواريخ السابقة والمعدلة، ويركز على ضمان الجودة (QA/QC). | استخدم هذا الأمر مع الإدارة العليا والمالك لحماية موقف الفريق. |
| **إشعارات الفريق الداخلي** | إبلاغ الفريق بالتغييرات الميدانية. | **Context:** بصفتي مهندس إدارة المشروع...<br>**Task:** اكتب رسالة للفريق الداخلي.<br>**Tone:** متعاون، مشجع.<br>**Requirements:** اذكر ما حدث والتغييرات المطلوبة... | إيميل وودي ومباشر يحدد خطة التكيّف للأسبوعين القادمين. | ممتاز لتفادي التوتر الميداني وإبقاء المعنويات عالية. |
| **تقرير مستجدات للمدير** | إحاطة المدير بالمخاطر واتخاذ قرار سريع. | **Context:** بصفتي مهندس إدارة المشروع...<br>**Task:** اكتب إيميل إحاطة وطلب توجيه.<br>**Tone:** مهني وموضوعي.<br>**Requirements:** اذكر المشكلة، التأثير، وحلين بديلين... | إيميل محدد النقاط يوضح تقييم الأثر الميداني وخيارات الحلول. | يضمن الشفافية ويساعد المدير على اتخاذ قرار سريع. |
